# Alsignal 内容生产工作流

## 目标

把一条人工输入或公众号素材变成可审核、可修改、可发布的内容。第一阶段支持内容入库、草稿版本、飞书审核和发布任务，模型生成与渠道适配器按任务逐步接入。

## 流程

```text
素材输入
  -> 草稿创建
  -> AI 生成
  -> 飞书预览
  -> 修改或确认
  -> 发布任务
  -> 渠道发布
  -> 发布记录
```

## 状态

- `draft`: 草稿已创建
- `generating`: 正在生成
- `review`: 等待人工审核
- `editing`: 用户要求修改
- `approved`: 用户确认发布
- `publishing`: 发布任务执行中
- `published`: 发布成功
- `failed`: 生成、审核或发布失败
- `cancelled`: 用户取消

## 第一阶段接口边界

- 素材入口使用现有管理员接口和外部 ingest 接口
- 草稿版本保存输入素材、提示词版本、模型、输出内容和操作者
- 审核任务保存飞书卡片回传所需的选项和过期时间
- 发布任务支持幂等键和重试次数
- 发布记录保存渠道、外部 ID、返回信息和错误信息

## 需要业务方确认的内容

- 公众号原始 ID 和发布主体
- 公众号发布方式是草稿箱还是直接发布
- X 账号和发布权限
- 飞书应用的 App ID、App Secret、机器人 Open ID 和卡片回传事件
- 长文、贴图文章的模板和字数要求
- 哪些来源允许全文改写和配图再发布

外部账号、密钥和 Cookie 只进入本机凭据配置，不进入 Git 仓库、规则文件或提示词。
